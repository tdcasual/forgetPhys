# 命运地图门禁（Map Gate）

Status: **Mandatory · 2026-09-06**  
对标：《80 Days》旅行地图可读性 + 印刷插画皮（非黑底针脚）。

## M1 · 地理可读
- 一眼可读欧洲海岸线；主要河流或山脉有插画暗示。
- 禁止纯黑虚空底 + 无地貌色带。

## M2 · 解锁状态
- 解锁城：暖金/可读高亮。
- 锁定城：墨灰/低饱和。
- 禁止霓虹 GPS 水滴、赛博描边。

## M3 · 城标
- 插画城徽 / 屋顶剪影 / 年代建筑符号。
- 禁止 Google Maps 式水滴 pin 作为最终皮。

## M4 · 跨层色温
- 地图与城市页同属「印刷插画」色温族。
- 禁止地图一黑一彩、城市页另一套赛博皮。
