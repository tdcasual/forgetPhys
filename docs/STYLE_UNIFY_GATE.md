# 跨层风格统一门禁（Style Unify Gate）

Status: **Mandatory · 2026-09-06**  
解决：照片级 bg + 二次元人、或写实脸 + 平涂身 的裂痕。

## S1 · 同章 Style block
- 同章出场的科学家与华生，生成提示词 **同一句 Style block**（见各角色 `_canon/identity` 附属 style 行）。
- 拒收：一人照片抠图、一人厚描边二次元。

## S2 · 线宽与颗粒
- bg 与立绘的线宽、颗粒、对比度须同级「插画游戏皮」。
- 允许场景光色不同（lab 冷 / lodge 暖），不允许渲染族不同。

## S3 · 外框统一
- 场所/城市页/图志外框同属羊皮纸或木刻图志族。
- Infinitas 实验窗 **内区**允许现代 UI；外框仍须纸质。

## 过检
并排：科学家 bust | 华生 bust | bg 裁切 | UI 对话框 — 四格同帧，目视无「两款游戏拼贴」。
