# UI / 图志门禁（UI Gate）

Status: **Mandatory · 2026-09-06**  
对标：《Pentiment》纸感、《80 Days》城市页清爽、Ren'Py 对话框。  
与 `SCENE_QA_GATE` G7 联动；冲突时以本文件 + SCENE_QA §5 修订为准。

## U1 · 对话框皮肤
- 羊皮纸底 + 墨线边；禁止系统灰条 / 现代聊天气泡当主对话皮。
- 字色深墨；行距可读。

## U2 · 导航不破沉浸
- **禁止**常驻顶栏「回到城市页」一类横贯画面的系统条。
- 返回城市/地图：仅在 `⋯` 菜单、场景出口按钮、或章节结束卡。

## U3 · 名牌
- **主名字**：对话框旁 Ren'Py-style **namebox**（说话人切换时清晰）。
- **胸微标**：可选，≤ 立绘宽 18%，不挡五官；过渡期可留，不得替代 namebox。
- 拒收：脚下大黑条、胸口大浮条抢脸。

## U4 · 演绎角标
- 仅虚构 / 时间压缩 / 对话演绎内容显示「演绎」。
- 教材可核对的史实句：**无角标**。

## U5 · 字体
- 全 UI 一套仿古/衬线族（图志、对话框、名牌）。
- 禁止混用系统默认无衬线作为主正文（代码/debug 除外）。

## 交付
每版 UI 改动交：`shots/qa/ui-{feature}.png` + 本表勾选。
