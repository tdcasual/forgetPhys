## 1. 比例（画幅 / 构图）

**问题拆开**
- **画幅**：舞台应锁 **16:9**（或 16:10）安全框；bg 按 **letterbox/pillarbox** 显示，禁止 cover 裁掉关键实验台。
- **立绘画幅**：半身 bust（3:4）不适合「坐在椅子上」；场景角色改为 **全身/膝上带姿态** 的竖构图，或 **带透明椅子的坐姿条**。
- **地图**：欧洲图与热点坐标按固定参考分辨率标定（建议设计稿 1920×1080），热点用百分比定位。

**方案**
1. CSS：`venue2d-bg-img` / map bg 改为 `object-fit: contain` + 两侧暗边，或预裁 16:9 安全区版本。
2. 美术交付两套：`bg/*-16x9.png`（场景）、`chars/*/{pose}.png`（含坐姿）。
3. 验收：实验台、椅子座面、人物脚/膝落点在同一透视地平。

## 2. 人物动作（姿态系统）

**现状**：`idle/speak/surprise` 都是站立半身。

**方案：姿态 + 表情分离**
```
asset: chars/{id}/{pose}__{emotion}.png
pose ∈ stand | sit-chair | lean-bench | point-screen | write-desk
emotion ∈ idle | speak | surprise | think
```
P0 最低集（卢瑟福）：
- `sit-chair__idle` / `sit-chair__speak`（租屋+实验室旁听）
- `lean-bench__idle`（实验台旁）
- `point-screen__speak`（讲大角散射）
伴灵（新人设）P0：
- `stand__idle` / `sit-stool__think`（可坐高凳，不漂浮）

对话 JSON：`"pose": "sit-chair", "emotion": "speak"`。  
**禁止**无接触点的「漂浮半身」。

## 4. 伴灵：改名 + 换形象

**废止**：飞灵、超大头、齿轮发卡、漂浮、派蒙式围巾精灵。

**推荐名（拍板候选）**：**微光**  
理据：硫化锌屏闪光 / 暗室「看见」粒子；好记、不二次元黑话、无商业 IP 味。备选：`荧`、`闪点`。

**形象方向（写实偏插画）**
- 人类比例（头身 ≈ 6–7 头身），少女或少年助手皆可，**站得住地面**。
- 着装：1900s 实验室助手（亚麻围裙/深色裙装或背带），可有护目镜挂胸前，**不漂浮**。
- 气质：好奇、会吐槽，但是「跟班实验助手」不是吉祥物。
- 仍可用轻度风格化线稿，但禁止 chibi。

路径：`assets/chars/char-weiguang/`（代码 id 从 `char-companion` 迁移）。

## 5. 人环比例审计规则（强制）

同框时：
1. **科学家身高** ≈ 背景门框/人身高参考的 0.85–1.0（若 bg 有远处小人，禁止拿远处小人当尺度）。
2. **伴灵与科学家**同头身体系，伴灵可略矮（0.85×），禁止 1.5× 头身差。
3. 坐姿：椅面与膝弯对齐背景椅；站姿脚底落在地线。
4. 验收截图带「比例尺叠层」（开发开关）：肩高线、桌面线。

## 6. 背景：史实 × 克制

**原则**：一张主光源 + 2–3 个可读道具；去掉堆满的瓶罐与多余行人。

| bg | 保留 | 删减/改 |
|---|---|---|
| map-europe | 欧洲轮廓、三城 | 去掉过多国界铁路图例；年代改为 **~1910**；热点外少烟柱 |
| city-manchester | 砖街、煤气灯、远烟囱 | 减泥污对比；UI 卡片缩小半透明，勿盖住街景主透视 |
| lab-coupland | 木桌、铅室/金箔台、荧光屏一点绿 | 减杂物；留「坐椅」给姿态；透视地平明确 |
| lodge-night | 煤气灯、书桌 | 同样留椅；少装饰 |

美术标注：`historical_ok` / `complexity: low`。

## 7. 导航：去掉「沉浸破坏顶栏」

**废止**：场所顶满宽羊皮纸条 + 「回城市页」大按钮。

**方案（推荐组合）**
1. **沉浸默认**：无顶栏；地点/年代改到对话框上方一行小字：`曼彻斯特 · Coupland · 1909`。
2. **退出**：右缘 **窄小「⋯」或地图折角** → 弹出：`城市页 / 图志 / 地图`（Esc 同）。
3. **实验台**：「去实验台」保留在对话区动作里，不进顶栏。
4. 城市页自身的「回地图」可保留在卡片内（城市页本就是菜单层）。
