# Visual Target / Style Bible — 物理编年图志

Status: Locked (2026-09-06)  
Audience: 美术资源 agent、实现、导演

## 1. 产品一句话
Web 上的编年史教育叙事：图志旅行进城，场所里见人、做实验；史实可追溯，关键瞬间要「好看且读得懂」。

## 2. 四层视觉目标（已锁）

| 层 | 对标 | 我们要做到 | 明确不做 |
|---|---|---|---|
| **图志 Atlas** | 《80 Days》地球/路线信息图 + 《文明 VI》式年代换肤 | 插画/扁平信息图；年代一换烟囱、灯、电车出现；节点可点 | 可步行开放大地图、AC Discovery Tour 全城闲逛 |
| **场所 Venue** | 《Heaven's Vault》有光的立体景 | 低中模模块化房间（实验室/书房/沙龙）；暖光、体积感、道具可读 | 影视级全屋高模、每城独一无二大街 |
| **角色 Character** | HV 风格化人 + 派蒙式伴灵 | **二次元立体（VRM/cel-ish）**；主轴 3 科学家 + 1 伴灵先精修 | 写实扫描脸；上百路人高模 |
| **对话/UI** | 《Pentiment》纸质/年谱气质 | 羊皮纸/铅印感面板；`interpretation` 角标「演绎」；引用可展开 | 现代手游炫光商城 UI |
| **实验 Lab** | 美术 > PhET，正确性 ≥ PhET | 暗室磷光、荧光闪点、库仑径迹要「哇」；读数诚实 | 粒子特效牺牲物理正确 |

## 3. 风格公式（强制）
```
时代写实布景 × 二次元角色 × 纸质年谱 UI × 科学特效克制炫
```
- 人可以二次元；**仪器与现象尽量物理可信**
- 场景偏 1900s 欧洲：砖、煤气灯、木桌、铅室、雾
- 禁止整屏无差别 AI 出图直接进包；AI 只做概念/贴图草稿，需人工收成套件

## 4. 色彩与光
- **图志**：有限色板（土色陆地 + 冷色水域或年代滤镜）；路线高对比
- **实验室**：暗底 + 磷光绿/荧光点（阴极射线、散射）
- **书房/沙龙**：暖钨丝/煤气灯；木与织物
- **UI**：米黄纸、赭石线、少量朱红强调（演绎角标）

## 5. P0 / P1 资产清单（范围锁）

### P0（必须）
1. 图志：1 时代 1 屏（曼彻斯特工业天际即可）+ 1 可进节点
2. Venue：Coupland Street **实验室** 1 套（墙/桌/铅室/金箔台/荧光屏）
3. 实验特效：α 径迹 + 荧光闪点 + 简单计数 UI
4. 角色：卢瑟福 **或** 通用实验员 stub + 伴灵 stub（可低精）
5. UI：对话框 + 「演绎」角标 + 简单引用抽屉

### P1（第一章）
- 图志换肤：剑桥 / 曼城 / 哥本哈根
- Venue：卡文迪什暗室、曼城 lab、哥本哈根**公寓书房**（非嘉士伯宅）
- 角色精修：Thomson、Rutherford、Bohr、伴灵（VRM）
- 英雄台：阴极射线管；散射保持；玻尔能级以 2D/轻 3D 面板为主

## 6. 授权与来源规矩
- 优先：CC0 / 明确可商用 / 自制 / 约稿
- Sketchfab 等下载必须记录授权进 `docs/art-provenance.md`
- 禁止：直接使用原神等商业角色资产；伴灵只「气质参考」
- 每张入包资产：`id / path / license / source_url / notes`

## 7. 验收口诀
- 静帧能不能让人看出「这是 1910 前后的欧洲」？
- 角色会不会和场景抢风格到出戏？（出戏则改光或线稿浓度，不改公式）
- 实验截图能不能让没玩过的人看出「粒子在被中心电荷推开」？
- UI 能不能一眼区分「教材结论」和「演绎」？
