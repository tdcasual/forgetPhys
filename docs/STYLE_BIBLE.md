# Visual Target / Style Bible — ForgetPhys（纯 2D）

Status: **Locked 2026-09-06 · Pure 2D**  
Audience: 美术资源 agent、实现、导演

## 1. 产品一句话
**ForgetPhys**（忘掉物理学家——为了记住）。Web 编年史教育叙事：**插画地图选命运之地 → 纸质章节图志 → 2D 场所对话 → Infinitas 实验窗**；史实可追溯；科学家为 **漫画立绘**。

## 2. 三层分工（强制，勿混皮）

| 层 | 对标 | 我们取什么 | 明确不取 |
|---|---|---|---|
| **结构** | 《80 Days》 | 地图 → 城市页 → 按钮 → 过场红线 | 矢量剪影配色当唯一画风 |
| **皮肤** | 《Pentiment》 | 羊皮纸/木刻图志、纸质对话框、演绎角标、旁注 | 中世纪服饰硬抄 |
| **实验** | 用户 Infinitas | iframe 原样；仅外框羊皮纸 | 要求仿真改成手绘 |

旧 3D（Civ 沙盘 / Heaven's Vault 场所 / VRM）**整层废弃**为实现主路径。

## 3. 风格公式
```
插画欧洲地理 × 漫画科学家立绘 × 纸质年谱 UI × Infinitas 实验嵌窗
```

## 4. 色彩与光
- **地图**：印刷插画感；解锁城暖金，锁定城墨灰
- **图志**：米黄纸、赭石线、少量朱红（演绎）
- **场所**：实验室偏冷磷光点缀；租屋暖煤气灯
- **实验窗**：外框纸质；内区保持 Infinitas 现代 UI

## 5. 角色（漫画形象）
- 漫画/插画立绘，半身 bust 默认；透明底 PNG
- 历史人物：可辨认 + 风格化（眼镜、胡须、发型锚点）
- **伴灵固定为「华生」**（`char-watson`）：记录者/追问者；**禁止**派蒙体、微光旧皮、商业游戏角色资产
- 华生 **脸锁 canon，服装随时代变**（见 `WATSON_ERA_OUTFIT_GATE.md`）——编年从古至今都跟，每章/城一套 `outfits/{era-slug}/`

## 5.1 历史人物立绘流水线（强制 · 2026-09-06）
1. **先找史实肖像** → `assets/chars/_historical_refs/` + provenance。
2. **再加工**立绘；辨认锚点 ≥2/3。
3. **禁止**无参考凭空美型化历史人物。
4. 华生不走史实演员脸；走 `_canon` + **时代换装**（W1–W6）。
