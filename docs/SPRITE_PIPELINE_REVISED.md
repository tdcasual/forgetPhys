## 1. 你的判断为什么对

1. **人椅分离**在实现上省事，但 AI 立绘 + 照片感家具很难对齐透视 → 必然「悬空/踩椅」。  
2. **半身大特写 + 全身小人**不是商业 VN 主流构图。  
3. **CSS `top:55%` 浮字**不等于胸牌：PNG 透明区很大时，55% 往往落在肚子/空白，看起来像乱飘的字幕条，字号/底板也不像金属名牌。

业界很少用「浮在立绘上的 HTML 字」当角色胸牌；名字几乎都在 **对话框 namebox**（Ren'Py 标准）。若坚持「胸牌感」，应是 **画进衣服的小铭牌** 或 **衣领旁的独立小徽章图**，而不是大块半透明条。

## 2. 成熟 2D/VN 到底怎么做（GitHub）

| 项目/文档 | 做法 | 我们可抄 |
|---|---|---|
| [Ren'Py LayeredImage](https://github.com/renpy/renpy/blob/master/sphinx/source/layeredimage.rst) | 坐姿可 **带桌子分层**：手臂 behind/infront table；坐姿精灵常含椅子或与桌分层 | **允许 sit 烘焙椅子**；高级再分层 |
| Ren'Py say/namebox | 名字在对话框上方 namebox 图，不贴身上 | 主名字用对话框小 namebox；胸牌仅作可选微标 |
| [ComfyUI_VNCCS](https://github.com/AHEKOT/ComfyUI_VNCCS) | 角色一致流水线：创角→服装→Pose Studio→情绪；Pose 可从参考图导入（含坐姿） | 美术侧以 VNCCS/同类 Pose Studio 出 sit |
| [sprite-forge](https://github.com/kitepon-rgb/sprite-forge-mcp) | bible→LoRA→任意姿势；**质量门禁**挡住坏资产 | 对齐我们 SCENE_QA + CHAR_CONSISTENCY |
| InstantID / IP-Adapter FaceID | 锁脸换姿势/衣服 | 换装、sit 带椅仍锁 `_canon/face` |

**商业 VN 常见布局（推荐改用）**
- **左右分列**：说话者略大/靠前，听者略小靠另一侧（经典 Ren'Py）  
- **半身（bust）统一**，底边对齐画面下 1/3  
- **坐姿**：直接生成「人坐在该场景风格椅子上」整图（透明底含椅），bg 去掉冲突空椅

## 3. 修订后的合成策略（强制二选一，禁止第三种烂法）

### 方案 A · 烘焙坐姿（优先，治生硬）
```
sit__think.png = 人 + 椅子（透视自洽），透明底
bg = 无对应空椅（或椅子被遮挡）
```
Gate：**允许**角色层含椅；**禁止** bg 再放一把同位置空椅。

### 方案 B · 分列缩小（治比例）
```
左 45%：科学家 bust
右 45%：华生 bust（scale 0.88–0.92）
底边同一水平线；中间留实验台/灯
```
Gate：禁止一人踩家具；禁止半身+全身混用。

### 废弃
- 全身小人站 bg 椅面  
- 无椅坐姿悬空 + CSS 硬拽锚点当长期方案

## 4. 名牌修订（必须达标）

### 主路径（业界标准）
- **对话框 namebox**：小横条贴在对话框左上，显示「卢瑟福」「华生」  
- 字号约 13–15px，有 namebox 底图（羊皮纸小条），**不**盖住立绘胸口  

### 可选「胸牌」微标（若仍要提醒）
- 尺寸：**≤ 立绘显示宽度的 18%**，高度约 **14–18px**  
- 样式：仿黄铜/纸质胸牌（细边、微斜 2–4°），不是大胶囊字幕  
- 锚点：相对 **角色不透明像素 bbox 的胸口**，不是整张 PNG 画布的 55%  
- 默认：**仅当前说话者**显示胸微标，或双方极小；避免两人胸口各挂一块抢戏  

当前实现（`top:55%` + 11.5px 半透明条）= **未达标**，需重做。

## 5. 生成验收流程（抄 VNCCS + sprite-forge）

```
1. Canon face（史实→加工）
2. Character bible / sheet（VNCCS 或 sprite-forge）
3. Pose Studio：站 / 坐(含椅) / 指 —— FaceID 锁脸
4. 自动门禁：脸并排 QA、透明边、禁双椅冲突
5. 入库 framing=bust|sit-baked；左右槽位元数据
6. 运行时：左右分列 + namebox；可选胸微标
```

## 7. 尺度硬约束（2026-09-06 · 拒收补丁）

真机曾把 `sit-with-chair` 按 bust 槽放大 → **椅子叠在桌面上**。用户判定：不如左右 bust。

**强制：**
1. `sit-with-chair` 必须按**房间比例**制作：椅座高度 ≈ bg 真实椅/桌裙比例；人物坐高 ≈ 桌后半身。  
2. 运行时若无法保证「椅腿在地板、不压桌面」，**禁用 sit-baked**，回退左右 bust。  
3. 验收：椅腿底边落在地平；桌面不得从椅座中间穿过；华生/科学家同尺度体系。
