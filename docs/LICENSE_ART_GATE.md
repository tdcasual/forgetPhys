# 美术授权与发布包门禁（License Gate）

Status: **Mandatory · 2026-09-06**  
强化 `BACKGROUND_AUTH` B6；教育非商用仍须归因清晰。

## L1 · refs 与发布隔离
- `_refs/` 可含 CC BY-SA、版权不明「仅审计」图。
- **发布包 / `final` 不得**直接嵌入仅审计图。

## L2 · provenance
- 每张 `final`（bg / 立绘 / UI kit）旁有 `provenance.md`：来源或生成方式、日期、授权结论。
- AI 生成须注明；若用版权训练争议模型，记一笔供日后替换。

## L3 · 总表
- `docs/art-provenance.md`（或目录总表）可列出 CC 素材归因；游戏内或 about 可打开简述。

## 拒收
无 provenance 的 final；把 Wikimedia BY-SA 原图当游戏贴图入库发布。
