## Extract template (for VoiceCard)

From a passage, extract only:

1. Typical sentence length / punctuation habits  
2. How disagreement is voiced (hedge, scoff, demand apparatus)  
3. Stock phrases OK to echo vs banned modern calques  
4. One rewritten sample line tagged interpretation  

Do **not** paste long copyrighted copyrighted prose into game JSON — paraphrase into original game lines.
