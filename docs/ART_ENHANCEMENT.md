# 美术增强与门禁优化建议（导演审计 · 2026-09-06）

对照：本项目现有门禁 + 《80 Days》《Pentiment》《Heaven's Vault》《Ace Attorney / 常见 VN》《Disco Elysium》生产习惯。

## 1. 现状诊断（已有 vs 缺口）

### 已有（方向对，继续用）
| 门禁 | 作用 | 对标 |
|---|---|---|
| `CHAR_CONSISTENCY` + InstantID | 脸不漂 | AAA 角色 bible / sheet |
| `BACKGROUND_AUTH` B1–B6 | 年代×地点建筑 | 纪录片美术 / Pentiment 史料室 |
| `SCENE_QA` G1–G8 | 人环比例、接触、光影 | VN 合成规范 |
| `SPRITE_PIPELINE_REVISED` | bust vs sit-baked 尺度 | Ren'Py 立绘槽位 |
| provenance / checklist | 授权与审计 | Indie 合规 |

### 仍缺（痛点来源）
1. **跨层皮不一致**：地图插画 / 城市页 / 场所 / 立绘 / UI 羊皮纸五层色温与线宽未锁「同一印刷机」
2. **UI 美术门禁弱**：图志、对话框、演绎角标、城市页按钮未单独验收（易回到「顶栏破沉浸」）
3. **道具/仪器层未独立**：磷光屏、阴极射线管、笔记本应是可点/可换道具，不是烤死在 bg 或立绘里
4. **音频/纸感反馈未进美术**：翻页、印章、墨迹（Pentiment 强项）零规范
5. **LOD / 变体矩阵不全**：每角色缺「情绪×服装年代×光环境」最小矩阵，导致现做现漂
6. **自动化过检几乎为零**：全靠人目检并排图，回归成本高
7. **地图层门禁空白**：命运地图仍无「地理可读 + 印刷插画」硬门禁
8. **STYLE_BIBLE 过期句**：仍写「伴灵派蒙级 / 微光」——与华生冲突，易误导美术

## 3. 建议新增门禁（按优先级）

### P0 · 立刻加（修已踩坑）

#### U · UI / 图志门禁
| ID | 标准 |
|---|---|
| U1 | 对话框=羊皮纸底+墨线；禁止系统灰条顶栏作为常驻导航 |
| U2 | 返回城市/地图只在 `⋯` 或场景出口，不破 16:9 画面顶 |
| U3 | 名牌最终形态=对话框旁 Ren'Py-style namebox；胸前浮标仅过渡 |
| U4 | 「演绎」角标仅出现在虚构/压缩时间内容；史实句无角标 |
| U5 | 全 UI 字体：衬线/仿古一套；禁混系统默认无衬线 |

#### M · 地图门禁
| ID | 标准 |
|---|---|
| M1 | 命运地图一眼可读欧洲海岸/主要山脉或河流暗示 |
| M2 | 解锁城暖金、锁定城墨灰；禁止霓虹针脚 |
| M3 | 城市 pin 为插画城徽/屋顶，非 Google Maps 水滴 |
| M4 | 地图与城市页色温同属「印刷插画」族，禁止一黑一彩裂开 |

#### L · 授权与发布包门禁（强化 B6）
| ID | 标准 |
|---|---|
| L1 | `_refs/` 可含 BY-SA / 仅审计图；`final` 与发布包禁止混入 |
| L2 | 每张 final 有 `provenance.md`：生成方式、模型、是否含版权训练争议备注 |
| L3 | 教育非商用声明写在 `art-provenance` 总表；CC 素材归因页可打开 |

#### S · 风格统一门禁（跨层）
| ID | 标准 |
|---|---|
| S1 | 同章科学家与华生 **同一 style block 句**（已有，强制执行） |
| S2 | bg 与立绘线宽/颗粒度同级：禁止「照片级 bg + 厚描边二次元人」或反过来 |
| S3 | 同城场所色温差 ≤ 指定 LUT 家族（lab 冷磷光、lodge 暖油灯允许，但同属羊皮纸外框） |

### P1 · 下周加（质量跃迁）

#### P · 道具层门禁
| ID | 标准 |
|---|---|
| P1 | 关键仪器（磷光屏、CRT、本子）独立 PNG 层，可换态，不烤死在角色里 |
| P2 | 道具有简短「史料卡」hover（可选）：名称+年代+一句用途 |
| P3 | 指屏动作食指落点对道具热区（已有 G6.2，接热区数据） |

#### V · 变体矩阵门禁
每角色最少：
```
framing: bust
emotions: idle | speak | think | surprise   （4）
era outfit: 按出场年代 1 套（华生按城换装）
lighting bake: lab-cool | lodge-warm | daylight  （或运行时 LUT）
```
缺格不得标「该角色完成」。

#### A · 音频纸感（轻量）
翻页、盖章、笔划——各 1 个 CC0；无声也可先占位，但 UI 交互不得「手游机械音」。

### P2 · 自动化（降回归成本）

| 工具 | 做什么 |
|---|---|
| `?debug=contact` | 地平/椅面/锚点十字（SCENE_QA 已要求，实现优先） |
| 脸相似度脚本 | canon face vs 新姿态 perceptual hash / embedding；阈值拒收 |
| 并排 QA 模板 | 固定四宫格：史实 / 旧皮 / 新皮 / 运行时合成 |
| CI 可选 | 缺 `_canon/face.png` 或缺 checklist 则 fail |

## 4. 流水线优化（少返工）

```
史料卡（建筑+肖像） 
  → _refs 入库（B1）
  → canon face + identity（脸锁）
  → bg final（空景，无人无椅冲突）
  → bust 立绘差分（不含家具）
  → 运行时合成 + SCENE_QA
  → 并排 QA 四宫格归档
```

**硬规则优化**：
1. **bg 永远空人**；椅可画但「可坐椅」须在 content 标 hotseat，或对话默认 bust 不碰椅
2. **禁止 sit-with-chair 烤进立绘**，除非整张是 room-scale 过场插画（非对话槽）
3. **一次批次出 sheet**，再出 pose；禁止 pose→pose 参考链
4. STYLE_BIBLE 立刻改掉「派蒙/微光」过期句，统一华生 + 服装随城
5. 美术交付物模板化：`final + checklist + provenance + auth-qa.png` 四件套，缺一拒收

## 7. 一句话

门禁已经「像 indie 制作管线」了；下一跳不是再堆条款，而是：**跨层统一印刷皮 + UI 门禁 + 道具分层 + 能自动拒收的脸/比例检查**——向 80 Days 的城市页清晰度、Pentiment 的纸感、VN 的立绘槽位看齐。
